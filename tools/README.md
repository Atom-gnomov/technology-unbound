# Генераторы ассетов

Скрипты, которыми нарисованы текстуры мода. Лежат в репозитории намеренно:
текстура — производное от скрипта, и править надо скрипт, а не PNG, иначе
следующий запуск затрёт ручную правку.

Нужен Python 3 с Pillow. Порядок запуска важен:

```bash
python tools/gen_textures.py      # предметы 16x16 — силуэты и материалы
python tools/upscale_textures.py  # те же предметы в 32x32 со штриховкой
python tools/gen_blocks_t2.py     # блокстейты, модели и «морды» машин T2
python tools/gen_gui.py           # фоны экранов
```

`upscale_textures.py` читает результат `gen_textures.py`, поэтому запускать
его отдельно бессмысленно — сперва первый, потом второй.

## Откуда взяты силуэты

Форма предметов снята с реальных образцов, а не придумана: у кирки головка
идёт дугой сверху с загибом вправо-вниз, рукоять — диагональю шириной три
из нижнего левого угла; у брони ванильные силуэты с тёмным контуром.
Смотрели `thaumiumpick`, `thaumiumaxe`, `thaumium{helm,chest,legs,boots}`,
`silveringot` из порта — **только геометрию**, которая в Minecraft общая для
всех модов. Сами файлы не копировались: `art_guide.md` §6 это запрещает
(лицензии), и запрет распространяется в том числе на текстуры порта.

Геометрия экранов (рамка, слот 18×18, раскладка инвентаря) и их палитра —
из скила `minecraft-basic-texture`.

## Что здесь заведомо слабое

Это работающая программистская графика, а не работа художника:

- слои брони на игроке (`models/armor/tempered_layer_*.png`) — простые
  пластины с процедурной штриховкой, силуэта доспеха на модели они не
  повторяют;
- у предметов нет проработанных фасок и бликов, только расчётная штриховка
  «свет сверху-слева»;
- «морды» машин нарисованы в 16×16, чтобы стыковаться с уже готовыми
  `machine_side/top/bottom`.

Любой из этих файлов можно заменить рисованным вручную — тогда достаточно
убрать соответствующий кусок из скрипта, чтобы запуск его не перетирал.
