# Генераторы ассетов

Скрипты, которыми сделаны текстуры мода. Лежат в репозитории намеренно:
текстура здесь — производное от скрипта, и править надо скрипт, а не PNG,
иначе следующий запуск затрёт ручную правку.

Нужен Python 3 с Pillow. Порядок важен:

```bash
python tools/gen_textures.py          # рисованные предметы (ключ) + заготовки
python tools/recolour_from_vanilla.py # основное: перекраска ванильных текстур
python tools/gen_blocks_t2.py         # блокстейты, модели и «морды» машин T2
python tools/gen_gui.py               # фоны экранов
```

`recolour_from_vanilla.py` перезаписывает почти всё, что нарисовал
`gen_textures.py`, — рисованным остаётся только таумиевый ключ (ванильного
аналога у него нет), которому скрипт лишь наводит объём.

## Откуда что взято

**Предметы и слои брони — перекрашенная ваниль.** Иконки инструментов и
брони сделаны из алмазного сета, слиток — из железного, чернильница — из
книги с пером, слои на игроке — из ЖЕЛЕЗНОЙ брони (она серая; алмазная
бирюзовая и после перекраски врёт по рисунку пластин). Перекраска идёт по
яркости: тон исходного пикселя раскладывается по нашей стальной рампе,
тёплые пиксели рукоятей — по деревянной, сверху садятся вис-вкрапления.
Силуэт ванильный, цвет наш.

Это не самодеятельность, а требование канона: `tempered_thaumium_tools.md`
§8 просит «силуэты алмазного сета». А слои брони иначе и не сделать — там
раскладка UV модели игрока, и нарисованное «на глаз» садится не по фигуре.

**Что можно и чего нельзя.** Ванильные ассеты в модах для Minecraft
использовать нормально. Запрет `art_guide.md` §6 — про текстуры **соседних
модов** (Thaumcraft, IC2, ASP): там чужие лицензии, и оттуда не берётся
ничего, даже из порта. С образцов порта снималась только геометрия силуэта,
общая для всех модов Minecraft.

**Экраны.** Геометрия рамки, слот 18×18 и раскладка инвентаря — по скилу
`minecraft-basic-texture`, палитра оттуда же (A #000000, B #555555,
C #c6c6c6, D #ffffff, E #373737, F #8b8b8b).

## Зависимость от клиентского jar

`recolour_from_vanilla.py` читает `1.12.2.jar` из папки игры; пути
перечислены в начале скрипта. На чужой машине jar лежит иначе — тогда
скрипт честно сообщает об этом и НИЧЕГО не трогает, а в репозитории
остаются уже собранные PNG. Добавь свой путь в `CANDIDATE_JARS`, если
нужно пересобрать.

## Что здесь всё ещё слабое

- «Морды» машин (`textures/blocks/*_front*.png`) нарисованы вручную в
  16×16, чтобы стыковаться с уже готовыми `machine_side/top/bottom`;
- таумиевый ключ — рисованный, объём ему наводится расчётом;
- перекраска не добавляет деталей, которых нет в ванильном оригинале: там,
  где алмазная кирка была гладкой, наша тоже гладкая.

Любой файл можно заменить рисованным вручную — тогда уберите его из
соответствующего словаря в скрипте, чтобы запуск его не перетирал.
